# nailong · 奶蛙跳一跳

[在线游玩](https://eyank3.github.io/nailong/)

这是一个按参考视频重建的响应式网页版本，支持手机触屏、电脑鼠标和空格键。游戏使用统一的世界坐标、等距相机投影和实际平台顶面碰撞来保持原版镜头与跳跃关系，角色替换为用户提供的奶龙立绘。

## 玩法

- 按住屏幕、鼠标或空格键蓄力
- 松开后跳向下一块方块
- 落点保留在方块顶面的实际位置，中心命中可得额外分数
- 掉落后播放大笑音效，并可重新开始
- 中心点命中会播放独立的“安迪”音效
- 游戏中提供静音、最高分、说明和分享按钮；不设置排行榜

## 文件

- `index.html`：游戏入口
- `style.css`：响应式界面与视觉样式
- `game.js`：跳跃、计分、碰撞和音效逻辑
- `assets/nailong.png`：从附件角色图处理出的透明奶龙立绘
- `assets/charge.mp3`：原蓄力音效
- `assets/center.mp3`：从用户提供视频中提取的“安迪”中心命中音效
- `assets/laugh.mp3`：从用户提供视频后段提取的大笑音效

双击 `index.html` 即可打开；如果浏览器限制本地音频播放，也可以把整个 `naiwa-jump` 文件夹放到任意静态网页服务器中访问。

## GitHub Pages

这是无需构建的静态网页。GitHub Pages 使用 `main` 分支的根目录发布，入口为 `index.html`。图片和音效使用相对路径，适用于 `/nailong/` 项目地址。

更新仓库中的游戏文件并推送到 `main` 后，GitHub Pages 会自动重新发布。原始参考视频和未使用的图片不包含在仓库中。
